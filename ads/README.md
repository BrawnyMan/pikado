# Sponsor images
Put PNG, JPG, JPEG, WEBP or GIF images in `left/` and `right/`.
Each side rotates independently in alphabetical filename order.
Default interval: 5 seconds; change or disable it in Admin → Settings.
New filenames are discovered within 15 seconds without a server restart.
Use new filenames when replacing an image so open displays pick up the change.
Portrait artwork works well (for example 600×900). Images are contained, not cropped.
Only local files are served; SVG, HTML and symbolic links are excluded.
No ad images are bundled. Empty folders show a sponsor placeholder.
